# UDM Pro SE Ubiquiti Router DHCP Local Logging scripts

Persistent **dnsmasq DHCP logging** on a UDM Pro SE (UniFi OS), with on-box
self-healing, an **off-box Raspberry Pi watchdog** that auto-restores logging if
it ever breaks (including after a firmware upgrade), 6-month log rotation, and
Gmail alerting.

> **Full reference:** see **[`docs/SETUP.md`](docs/SETUP.md)** — it explains every
> file, the architecture, setup-from-scratch, operations, disaster recovery,
> security, and where every copy lives.

## Why this exists

UniFi OS stores dnsmasq's runtime config in `/run` (tmpfs, wiped on reboot) and
**regenerates it on every reprovision**, which silently deletes any custom
`log-facility` directive — so DHCP logging stops without warning. A firmware
upgrade additionally wipes `/etc`, removing the systemd units. This project makes
DHCP logging survive all of that.

## Architecture (3 layers)

```
/run/dnsmasq.dhcp.conf.d/dhcp-logging.conf   <- what dnsmasq actually reads
        ▲ regenerated by
Layer 1  ON-BOX self-heal   service + .path (~1s) + .timer (~60s)   [reboot, reprovision]
        ▲ re-installed by
Layer 2  OFF-BOX Pi watchdog  every 15 min: detect broken -> restore -> email
                              [firmware upgrade, /etc wipe, /data loss, Layer-1 failure]
Source of truth: this Git repo (private) — cloned on the Pi, pulled --ff-only before runs
```

## Layout

| Path | What |
|------|------|
| `udm/udm-dhcp-logging-setup.sh` | Authoritative bootstrap; installs/restores everything on the UDM (the Pi's deep-restore payload) |
| `udm/authorized_keys.template` | Hardened format for the Pi's root key on the UDM |
| `pi/udm-dhcp-logging-check.sh` | The watchdog: probe + restore + verify |
| `pi/notify-gmail.sh` | Gmail SMTP alerter (reads a never-committed secret) |
| `pi/install-pi-watchdog.sh` | Installs the Pi key, host-key pin, and systemd timer |
| `pi/*.service`, `pi/*.timer` | Pi systemd units (15-min watchdog) |
| `config.env.example` | Copy to `config.env` (gitignored) to override defaults |
| `docs/SETUP.md` | **Comprehensive reference** |

## Quick start

1. **UDM:** `ssh root@<UDM_IP> 'bash -s' < udm/udm-dhcp-logging-setup.sh`
2. **Pi:** clone this repo to `~/udm-dhcp-logging`, run `pi/install-pi-watchdog.sh`,
   authorize the printed public key on the UDM, create `~/.config/udm-watchdog/gmail.secret`.
3. Verify: `pi/udm-dhcp-logging-check.sh` prints `probe -> OK`.

See [`docs/SETUP.md`](docs/SETUP.md) for the detailed runbook.

## Security

- The Pi holds a **dedicated, source-IP-restricted root key** to the UDM. Private
  key and the Gmail app password live **only on the Pi** and are never committed.
- This repo is **private** — it documents home-network topology and root-persistence
  techniques. No secrets are stored in it (enforced by `.gitignore` + a pre-commit
  secret scan).
